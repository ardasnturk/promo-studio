## Promo Studio 1.3.1

### Instagram login without a Facebook Page

Meta no longer offers new apps the old "API setup with Instagram login", so
**Instagram login** in Promo Studio stopped working for them: Instagram just
opened its home page. 1.3.1 uses Meta's replacement, **Instagram API with
Unified Login**.

* In your Meta app, create the Unified Login configuration (**Use cases →
  Instagram API → Customize → API setup with Unified login**) and register an
  `https` redirect URL. Meta asks you to link a business portfolio first.
* In **Settings → Instagram → Meta App**, enter the **Configuration ID** and
  the redirect URL, then **Log In with Instagram**, choose **Continue with
  Instagram** and share your account.
* No Facebook Page is needed, and the token doesn't expire.

Step by step: [docs/SETUP.md](https://github.com/ardasnturk/promo-studio/blob/main/docs/SETUP.md#instagram-login-alternative).
Accounts connected with Facebook login keep working as before.

### Fixes

* **Continue with Instagram** on Meta's login page did nothing: the login
  window ignored pages Meta opens as popups.
* The login window is wider, so Meta's business login pages and their buttons
  fit.
* Switching the connection type no longer overwrites a redirect URI you
  entered yourself.

Includes everything from [1.3.0](https://github.com/ardasnturk/promo-studio/releases/tag/v1.3.0).
