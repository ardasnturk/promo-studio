## Promo Studio 1.2.1

### Fixed

* **Promo Templates can be installed again.** Promo Studio offered to install
  its template library only while no library was linked at all, so an old
  entry, such as a library whose folder was renamed, hid the offer for good. It
  now offers Promo Templates whenever that library itself isn't linked: on
  launch, in the sidebar, and in a new row under Settings → Updates, where you
  can also choose a copy you already downloaded. Once linked, the same row shows
  its version and offers updates.
* A library whose folder was moved or deleted now shows "Folder not found" in
  Settings → Updates instead of a dash.

Includes everything from [1.2.0](https://github.com/ardasnturk/promo-studio/releases/tag/v1.2.0).
