## Promo Studio 1.2.4

### Fixed

* **Real logos for every club, not just one.** The director only listed logos
  it had a confirmed image link for, so in a match video the opponent often
  appeared as a drawn badge (e.g. VfB Stuttgart next to Galatasaray's real
  crest). Every club, league or brand in the video is now listed, with its
  English Wikipedia article as a fallback: Promo Studio downloads the
  article's crest when there's no direct link or the link fails.
* The kit's `Matchup` scoreboard can show real logos, and a new `Logo`
  component shows one with the same pop-in as a badge.

### Remote Code

* Template libraries such as Promo Templates can be used from the phone:
  `generateFromSkill` runs a video template and `generateIdeas` researches
  trend ideas. Each library in the state now carries its templates'
  suggested project and the latest ideas. Needs Remote Code 1.5.0 (build 15).

Includes everything from [1.2.3](https://github.com/ardasnturk/promo-studio/releases/tag/v1.2.3).
