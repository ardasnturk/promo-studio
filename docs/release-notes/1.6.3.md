## Promo Studio 1.6.3

### Fixed

Instagram's upload service sometimes loses a video: it reports "File not found"
(error 1363008) with no bytes received, although the file is fine and the same
video goes through later. Promo Studio now gets past this by itself:

* After a refused upload, it waits 30 seconds and starts again.
* If that fails too, Instagram fetches the video from a temporary Cloudflare
  link, the way it fetches pictures. The link is random, serves only that file
  and closes right after. This needs cloudflared; without it, the step is
  skipped.
* If that fails too, it tries the upload once more after three minutes.

The status line shows each step. This works for Reels and video stories, and a
post can take a few minutes longer when these steps run.

Includes everything from [1.6.2](https://github.com/ardasnturk/promo-studio/releases/tag/v1.6.2).
