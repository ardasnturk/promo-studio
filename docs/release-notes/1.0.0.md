## Promo Studio 1.0.0

The first public release. Promo Studio makes promo videos for the apps you build: it reads your app's source code,
writes a storyboard from your prompt, has Claude Code direct and code a custom Remotion video, renders it with
voiceover and posts or schedules it as an Instagram Reel.

### Highlights

* **Promo films directed by Claude.** Write a prompt; Claude researches facts on the web if needed, writes a
  scene-by-scene storyboard, codes the video in Remotion with the built-in motion kit, checks its own frames and
  revises it step by step. Every storyboard and code version can be restored.
* **Quick templates** from your app's screenshots, scripts and captions in ten languages, and **Copy in Another
  Language** for the whole video.
* **Voiceover** with Gemini TTS (optional) and a royalty-free background beat.
* **Instagram** publishing and scheduling through the official APIs, with views and reach afterwards. Optional:
  **Save Video…** and **Share** export the MP4 without an account.
* **Promo Templates**, the template library with ready-made formats and Claude Code skills, installs and updates from
  inside the app.
* **Setup checklist** on first launch: checks Claude Code, Node.js and Remotion and installs the video engine.
* **Remote control from iPhone** with [Remote Code](https://github.com/ardasnturk/remote-code).
* **Updates** from GitHub Releases, verified by SHA-256 and code signature.
* Interface in English, Turkish, German, Spanish, French, Italian, Portuguese (Brazil), Japanese, Korean and Simplified Chinese (the same languages as Remote Code); it follows the language of your Mac.

### Requirements

macOS 15 or later, [Claude Code](https://claude.com/claude-code) signed in, Node.js 20 or later. See
[docs/SETUP.md](https://github.com/ardasnturk/promo-studio/blob/main/docs/SETUP.md).

### Install

Download `PromoStudio-1.0.0.dmg` below and drag Promo Studio to Applications, or:

```sh
brew tap ardasnturk/promo-studio https://github.com/ardasnturk/promo-studio
brew install --cask promo-studio
```
