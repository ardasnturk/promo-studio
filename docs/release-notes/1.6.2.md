## Promo Studio 1.6.2

### A second Gemini key

Voiceover no longer has to stop when your Gemini key runs out of quota.

* **Settings → Voiceover** has a new optional field for a second Gemini API key.
* When the first key runs out of its daily quota, or stays rate limited, the
  second takes over and the voiceover goes on.
* If both are out, you see the same message as before, with the option to
  produce the video without voiceover.

Google counts quota per project, not per key, so the second key must come from a
different Google project. A key from the same project adds nothing.

Includes everything from [1.6.1](https://github.com/ardasnturk/promo-studio/releases/tag/v1.6.1).
