## Promo Studio 1.3.0

### Videos without a project

Not every video is about one of your apps, not every project has an Instagram
account, and not every account has a project. 1.3.0 separates the three.

* **Videos** (new in the sidebar) — **New Video…** makes a video from a prompt
  or from a library template. Without a template, Claude directs it from
  scratch: a storyboard first, nothing rendered until you approve it. A
  project and an Instagram account are both optional; pick any account with
  any project, or neither. Without a project the video isn't about any app.
* **Templates without a project** — running a Promo Templates template no
  longer asks for a project.
* **An account per post** — every post's Publish tab has its own Instagram
  account picker; without a choice the project's account is used.
* **Save Video…** in every post, so you can download it and post it yourself
  without connecting an account.
* **New Template…** — describe a video template in a library's page and Claude
  Code adds it to the library: a skill and a reference composition that follow
  the library's rules, checked with a test frame. It doesn't commit anything.

### Remote Code

All of this works from the phone with Remote Code 1.5.0 (build 16): New Video,
the account per post, Save to Photos and New Template. In the control API,
`createDirectedPost` and `generateFromSkill` take an optional `projectId` and
an `accountId`, `updatePost` takes `accountId`, and `createTemplate` is new.
A post's `projectId` may be null.

Includes everything from [1.2.4](https://github.com/ardasnturk/promo-studio/releases/tag/v1.2.4).
