# Code of conduct

Promo Studio follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Please read it before taking part in issues, discussions or pull requests.

In short:

* Be respectful and kind; assume good intent.
* Critique ideas and code, never people.
* No harassment, discrimination, sexualised language or personal attacks, in
  public or in private messages.
* Keep discussions on topic and help newcomers find their way.

## Reporting

If someone violates this code of conduct, contact the maintainer
([@ardasnturk](https://github.com/ardasnturk)) privately, for example through a
private [advisory](https://github.com/ardasnturk/promo-studio/security/advisories/new).
Reports are handled confidentially.
