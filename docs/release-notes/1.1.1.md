## Promo Studio 1.1.1

### Fixed

* **Updates install again.** Installing an update from inside Promo Studio
  stopped with an invalid code signature, although the update was signed and
  notarized: the disk image's window design marked the app in a way the strict
  signature check rejects. The disk image no longer does, and the updater
  ignores that marker.

Includes everything from [1.1.0](https://github.com/ardasnturk/promo-studio/releases/tag/v1.1.0).
